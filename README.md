# MIT-WPU Department of Sports — official website

> **Brand (25 Nov 2026):** this is the website of the **MIT-WPU Department of Sports**. Sports Sphere is the university's student sports club: it is credited on the events it helps run and on the "Join the student club" page, but it is not the site's brand.

Static site (HTML + CSS + vanilla JS). There is no build step and nothing to install, so it can be hosted anywhere (university server, Netlify, GitHub Pages, etc.).

## Live site (Vercel)

https://mitwpu-sports.vercel.app (Vercel project `mitwpu-sports-website`; the old address https://sports-sphere-website.vercel.app still works). The site is **not linked to the
registration platform yet**: `registration_portal` in `content/settings.csv` is empty, so Register buttons go to the events calendar.
Redeploy after any change (edits to `content/*.csv` included):

```bash
npx vercel@latest deploy --prod
```

**Visitor statistics:** Vercel Web Analytics is enabled for the project (no cookies, no personal data). See it in the Vercel dashboard → `mitwpu-sports-website` → Analytics. The loader in every page skips localhost.

`.vercelignore` keeps `tools/`, this README and `content/HOW-TO-UPDATE.md` off the live site.

## Structure

| File | Page |
|---|---|
| `index.html` | Home: hero, Peace Studies, sports, Dronacharya Complex, events, honours, news |
| `about.html` | Purpose, three pillars, milestones, leadership |
| `sports.html` | Filterable sports grid, facilities, team trials and FAQ |
| `events.html` | Hoop It Up, Sports Summit, 2026–27 calendar (auto-marks Completed / Next up by date), registration form |
| `partner.html` | Why partner, 6 sponsorship tiers, benefits table, previous sponsors, testimonials, enquiry form |
| `contact.html` | Contact details, enquiry form, map |
| `join.html` | Join Sports Sphere: teams students can join (event management, media, design, marketing, sponsorship, volunteering), how it works, application form. For non-athletes; athletes register per tournament from the events calendar |
| `teams.html` | University teams, coaches and athletes (from `teams` + `people`) |
| `facilities.html` | Venues with location, features and guidelines (from `facilities`) |
| `achievements.html` | Achievement archive, filter by sport / year / level, search (from `achievements`) |
| `news.html` | All news and notices, filter by type, search (from `news`) |
| `gallery.html` | Photos and videos, filter by sport / event / academic year, lightbox (from `gallery`) |
| `search.html` | Site-wide search across pages, sports, events, news, achievements, facilities, people, teams |
| `sport.html?s=<slug>` | One page per sport, built from the tables |
| `event.html?e=<slug>` | One page per event (slug = title + start date), with results and photos |
| `sitemap.xml`, `robots.txt` | Generated by `tools/build.py` |
| `assets/css/style.css` | Design system (brand tokens at the top) |
| `assets/js/main.js` | Mobile nav, scroll reveals, counters, filters, form validation |

**Content (events, sports, teams, people, achievements, facilities, gallery, news, results, sponsors, stats, settings):** each table has a `status` column (empty/published, draft, archived). It lives in the tables in `content/` or in a Google Sheet (set `sheetId` in `assets/js/config.js`). `assets/js/content.js` reads them live in the browser. The club's guide is [content/HOW-TO-UPDATE.md](content/HOW-TO-UPDATE.md). The site must be served over http(s), not opened as a file, for the tables to load. Add `?preview-date=YYYY-MM-DD` to any URL to preview a future date.

**Registration:** not linked to the platform yet (on hold). Each event's `register_link` can hold a form link meanwhile. When it is time to link the platform, set its address once as `registration_portal` in `content/settings.csv` (or the Sheet's `settings` tab). The header, footer and banner **Register** buttons (marked `data-register` in `tools/build.py`) then open `<portal>/register`, an event whose `register_link` is `portal` links there too, and a footer "Check my registration" link opens `<portal>/status`. Empty = buttons go to the events calendar.

**Page copy and layout:** the rest of the copy, the header/footer, sports list and sponsorship tiers live in `tools/build.py`. Edit it, then run `python3 tools/build.py` from the project root to regenerate the pages. Don't hand-edit the HTML files, because the next build overwrites them.

## How the MIT-WPU Brand Book 2026 is applied

| Rule (page) | Implementation |
|---|---|
| Digital font is Lato (p.12) | Lato 400 / 700 / 900 from Google Fonts |
| Colour (Established brand palette) | Primary palette 1 only, never mixed with palette 2's Deep Red: Navy Blue `#11468F`, Orange `#FFA500`, Peach `#FFE5B4`, plus their tints/shades. Primary buttons are orange with deep navy `#0B2A57` text. Tokens are at the top of style.css |
| Headline | "Play. Compete. Represent MIT-WPU." ("Fueling Passion, Building Champions" is the Sports Sphere club's tagline and is no longer used) |
| Headline leading 80/72, subhead 40/44 (p.14) | `.display` line-height 0.9, `.h3` 1.1 |
| Logo | The site is MIT-WPU's own, so the MIT-WPU compact logo leads the header (left), followed by "Department of Sports". Logo files were cut at high resolution from the Brand Book: `assets/img/logo/mitwpu-logo-compact(-white).png`, `mitwpu-logo-master(-white).png` |
| Logo clear space = height of "M" (p.7) | Gap and divider around the header logo |
| Minimum digital logo size 60px (p.6) | Header logo is 62px tall at all screen sizes |
| White logo on navy (p.5) | White version used on navy header and footer |
| Branding in header/footer on long documents (p.6) | Logo in header and footer, wordmark in footer |
